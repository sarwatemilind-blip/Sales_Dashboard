# Adonis Incentive Calculator

Sales Performance Calculator for Adonis FY 2026–27.

## Live Demo
The application is hosted live on GitHub Pages:
[https://mihika-sarwate.github.io/adonis-incentive-calculator/](https://mihika-sarwate.github.io/adonis-incentive-calculator/)

## Features
- **Monthly, Bimonthly, Annual, Pillar Brand, BOTY, and Hygiene Incentive Calculations**
- Dynamic progress indicators and interactive active-slab highlights.
- Clear breakdown of all categories combined in a Summary dashboard.
